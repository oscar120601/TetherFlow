## 3. Wi-Fi 自動監控流程

## 10. 錯誤處理流程

```
┌─────────────────┐
│   執行操作      │
│ (啟動/停止/etc) │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   try-catch     │
│   包裹執行      │
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌───────┐  ┌────────┐
│  成功  │  │  失敗  │
└───┬───┘  └────┬───┘
    │            │
    │            ▼
    │       ┌─────────────────┐
    │       │   捕捉錯誤      │
    │       │ • 錯誤訊息      │
    │       │ • 堆疊追蹤      │
    │       └────────┬────────┘
    │                │
    │                ▼
    │       ┌─────────────────┐
    │       │   記錄錯誤      │
    │       │   到 history    │
    │       └────────┬────────┘
    │                │
    │                ▼
    │       ┌─────────────────┐
    │       │   回傳錯誤      │
    └──────►│   給前端        │
            │   (HTTP 400/500)│
            └────────┬────────┘
                     │
                     ▼
            ┌─────────────────┐
            │   前端顯示      │
            │   錯誤通知      │
            │   (Toast)       │
            └─────────────────┘
```
