## 🎯 核心概念

```
┌─────────────────────────────────────────────────────────┐
│                    TetherFlow 運作原理                    │
├─────────────────────────────────────────────────────────┤
│                                                          │
│   MacBook (TTL=65) ──→ 手機熱點 (-1) ──→ 電信公司        │
│        ↑                      ↓                          │
│   修改封包特徵            TTL=64                         │
│   看起來像手機          電信公司以為是手機直接發出        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 📋 功能對照表

| 功能 | 用途 | 建議設定 | 使用時機 |
|------|------|----------|----------|
| **TTL 修改** | 隱藏 MacBook 身份 | 65 | 每次連熱點 |
| **MTU 修改** | 匹配行動網路特徵 | 1400 | 與 TTL 一起 |
| **Wi-Fi 監控** | 自動啟動偽裝 | 啟用 | 常用同一熱點 |
| **DNS 加密** | 保護瀏覽隱私 | Cloudflare | 隨時 |
| **流量整形** | 管理頻寬分配 | 依需求 | 熱點工作時 |

## 🔧 常用設定組合

### 組合 A：基本偽裝（推薦新手）
```yaml
TTL: 65
MTU: 1400
Wi-Fi 監控: 啟用
自動啟動: 是
DNS: Cloudflare
```

### 組合 B：進階隱私
```yaml
TTL: 65
MTU: 1400
Wi-Fi 監控: 啟用
DNS: Quad9 (更安全)
流量整形: 限制背景下載
```

### 組合 C：會議模式
```yaml
TTL: 65
MTU: 1400
流量整形: 
  - Zoom: 不限速
  - Steam: 限制 1 Mbps
  - Dropbox: 限制 500 Kbps
```

## 🐛 常見問題速查

### Q: 啟動偽裝失敗？
**檢查清單：**
- [ ] 是否已輸入並儲存密碼？
- [ ] 是否有管理員權限？
- [ ] Wi-Fi 是否已連接？

### Q: 如何確認偽裝生效？
```bash
# 檢查 TTL
sysctl net.inet.ip.ttl
# 應該顯示 65

# 檢查 MTU
networksetup -getmtu Wi-Fi
# 應該顯示 1400
```

### Q: 忘記停止偽裝就關閉？
**不用擔心！** 設定會在下次啟動時自動還原。
手動還原：
```bash
sudo sysctl -w net.inet.ip.ttl=64
sudo networksetup -setmtu Wi-Fi 1500
```

## 💡 Pro Tips

1. **首次設定** - 建立 Profile 後開啟「自動啟動」，一勞永逸
2. **定期測速** - 每次換熱點先測速，了解網路品質
3. **DNS 建議** - 日常用 Cloudflare，存取敏感網站用 Quad9
4. **流量整形** - 手機熱點必開，省下寶貴流量
5. **快捷鍵** - 記住 `Cmd+Shift+T`，比點滑鼠快
